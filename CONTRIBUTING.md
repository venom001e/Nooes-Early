# Contributing to Nooes Website

Thank you for your interest in contributing to the Nooes website!

## Development Setup

**Prerequisites:** [Node.js](https://nodejs.org/) 24+.

```bash
npm install
npm run dev
```

Before submitting changes, make sure the project checks pass:

```bash
npm run check   # lint + typecheck + build
```

## Guidelines

1. Make focused changes and ensure all checks pass.
2. Follow existing code style and conventions.
3. Write clear commit messages.
