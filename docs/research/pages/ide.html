It is Command Code, now inside your editor. Chat beside your code, review proposed edits as native diffs, and keep working without interruptions.

Visual Studio Code 1.106 or newer and Cursor, in beta today. The JetBrains IDEs are coming soon.

Search for "Command Code" in the Extensions view of VS Code or Cursor and install it. VS Code installs it from the Visual Studio Marketplace, and Cursor from Open VSX. You can also run cmd --ide-setup from the Command Code CLI, which installs it into every supported editor it finds. Then open it from the activity bar and sign in.

No. The extension only needs a Command Code account. If you already use the CLI, your sessions, taste, skills and MCP servers are shared, so you pick up where the terminal left off. A few terminal-first commands stay CLI-only.

Yes. Command Code IDE extension sees the file you are editing and the lines you have selected, so "fix this" just works, with no paths or line numbers to paste. Type @ to add other files or folders, or attach up to six images. To stop sharing selections, turn off commandcode.context.autoAttachSelection.

This is a beta, so bugs are expected and welcome. Run /feedback, open a GitHub issue with what you did, what you expected and what happened, or come talk it through on Discord.
